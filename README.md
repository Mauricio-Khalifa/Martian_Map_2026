## Estructura del Repositorio

- `/docs`: Documentación, presentaciones y matriz de brechas.
- `/src`: Código fuente del frontend (React + TypeScript).
- `/data`: Datos crudos.

## Instrucciones para subir al repositorio

1. Inicializar git (si no lo has hecho):
   ```bash
   git init
   ```
2. Añadir los archivos:
   ```bash
   git add .
   ```
3. Hacer el commit inicial:
   ```bash
   git commit -m "Estructura inicial del proyecto organizada"
   ```
4. Añadir el repositorio remoto y subir:
   ```bash
   git remote add origin https://github.com/martianmap2026/Martian_Map_2026.git
   git branch -M main
   git push -u origin main
   ```
